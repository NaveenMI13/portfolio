# Option 4: Minimal Dark Theme Portfolio

## Features
- 🌓 Dark/Light theme toggle with localStorage persistence
- 🎨 Minimal and modern design
- 📱 Fully responsive mobile-first design
- ⚡ Smooth animations and transitions
- 🎯 Auto-hiding navigation on scroll
- 💫 Fade-in animations on scroll
- 🚀 Lightweight and fast

## Setup Instructions

1. Simply open `index.html` in your browser
   - Double-click the file, or
   - Right-click and select "Open with" → your browser

## No Build Process Required!

Pure HTML/CSS/JS - just open and view!

## Features Included

- **Theme Toggle**: Switch between dark and light modes
- **Minimal Design**: Clean and distraction-free interface
- **Smooth Animations**: Subtle and professional animations
- **Timeline Layout**: Professional experience presentation
- **Responsive**: Works perfectly on all devices
- **Auto-hide Navigation**: Navigation hides on scroll down
- **Professional Profiles**: LinkedIn, Naukri, and Indeed profile links integrated

## Customization

- **Colors**: Edit CSS variables in `styles.css` under `:root` and `body.light-mode`
- **Accent Color**: Change `--accent` variable for different accent colors
- **Content**: Modify directly in `index.html`

## Tech Stack
- HTML5
- CSS3 (with CSS Variables & Grid)
- Vanilla JavaScript
- Font Awesome Icons
- LocalStorage for theme persistence
